📌 프로젝트 개요

**모블시네마**는 C#과 Windows Forms를 활용한 영화 예매 키오스크 프로젝트입니다. 사용자는 영화 목록에서 작품의 상세정보와 예고편을 확인하고, 관람 날짜와 상영 시간을 선택한 뒤 좌석을 지정할 수 있습니다.

좌석은 5행 × 10열의 버튼으로 동적으로 생성되며, 선택 상태에 따라 색상이 변경됩니다. 선택한 좌석 정보는 결제 화면으로 전달되고, 성인·어린이 인원에 따른 관람 요금을 계산할 수 있습니다.

현재 버전은 **예매 및 결제 과정을 체험하는 시뮬레이션**입니다. 실제 결제 승인이나 예매 내역의 데이터베이스 저장은 포함하지 않습니다.

## 🎥 시연 영상 및 화면

> 시연 영상과 실제 실행 화면 추가 예정

| 화면 | 소개 |
|------|------|
| 메인 | 영화 포스터와 상세정보·예매 버튼 |
| 영화 상세정보 | 작품 정보, 예고편 연결, 좋아요 |
| 상영 일정 선택 | 관람 날짜와 상영 시간 선택 |
| 좌석 선택 | 좌석 배치 및 선택 상태 표시 |
| 결제 및 예매 확인 | 선택 좌석, 관람 인원, 총액, 결제 수단 표시 |

## ⚙️ 주요 기능

### 영화 탐색 및 상세정보

| 기능 | 설명 |
|------|------|
| **영화 목록** | 스파이더맨: 브랜드 뉴 데이, 호프, 모아나의 포스터와 선택 버튼 제공 |
| **상세정보 확인** | 영화별 상세정보 화면으로 이동 |
| **예고편 연결** | Microsoft Edge에서 영화별 YouTube 예고편 열기 |
| **좋아요** | 버튼 클릭 시 해당 화면의 좋아요 수 증가 |
| **예매 진입** | 메인 화면 또는 상세정보 화면에서 예매 화면으로 이동 |

### 상영 일정 및 좌석 선택

| 기능 | 설명 |
|------|------|
| **상영 일정 선택** | 날짜 선택과 상영 시간 버튼을 통한 예매 진행 |
| **날짜 선택 확인** | 날짜를 선택하지 않으면 안내 메시지 표시 |
| **좌석 동적 생성** | 반복문으로 A1~E10의 총 50개 좌석 버튼 생성 |
| **좌석 선택·해제** | 클릭 시 회색 ↔ 초록색으로 전환하고 선택 목록 갱신 |
| **좌석 선택 확인** | 좌석을 하나 이상 선택해야 다음 화면으로 이동 |
| **선택 정보 전달** | 선택 좌석 목록을 결제 화면에 전달하여 표시 |

### 요금 계산 및 결제 시뮬레이션

| 기능 | 설명 |
|------|------|
| **관람 인원 입력** | 성인·어린이 구분 및 인원 수 입력 |
| **입력 항목 추가** | 인원 추가 버튼으로 관람 구분·인원 컨트롤 동적 생성 |
| **총액 계산** | 성인 16,000원, 어린이 10,000원을 기준으로 결과 버튼 클릭 시 합산 |
| **결제 수단 선택** | 신용카드·무통장입금·포인트 및 수단별 세부 항목 표시 |
| **환불 안내 확인** | 예매 취소 및 환불 동의 여부에 따른 안내 메시지 표시 |
| **결제 확인** | 선택한 결제 방법과 금액을 메시지로 표시한 뒤 앱 재시작 |

## 🔄 화면 구성 및 데이터 흐름

```text
메인 화면 (Form1)
 ├─ 영화 상세정보 → 예고편 / 좋아요 / 예매하기
 └─ 예매하기
      ↓
날짜·상영 시간 선택
      ↓ 선택한 날짜와 시간을 전달
좌석 선택 (A1~E10)
      ↓ 선택 좌석 목록을 전달
결제 및 예매 확인 (mocal)
      ↓ 관람 구분·인원 입력 → 총액 계산 → 결제 수단 선택
확인 메시지 표시 → 앱 재시작 → 메인 화면
```

### 주요 구현 방식

- **이벤트 기반 화면 전환**: 버튼의 Click 이벤트에서 다음 Form을 생성하고 `Show()` 또는 `ShowDialog()`로 표시합니다.
- **생성자를 통한 정보 전달**: 상영 날짜·시간을 좌석 화면에 전달하고, `List<string>` 형태의 선택 좌석을 결제 화면에 전달합니다.
- **동적 UI 생성**: 좌석 버튼과 추가 인원 입력 컨트롤을 실행 중 생성하고 이벤트를 연결합니다.
- **선택 상태 관리**: 좌석을 클릭할 때 버튼 색상과 선택 목록을 함께 변경합니다.
- **관람 요금 계산**: 각 입력 항목의 관람 구분에 해당하는 단가와 인원 수를 곱해 합산합니다.

## 📁 프로젝트 구조

```text
movie-kiosk-upload/
├── project.sln                  # Visual Studio 솔루션
└── project/
    ├── project.csproj           # .NET 6 Windows Forms 프로젝트 설정
    ├── Program.cs               # 프로그램 시작 및 메인 화면 실행
    ├── Form1.cs                 # 영화 목록 메인 화면
    ├── Form2.cs                 # 스파이더맨 상세정보 (spyderInfo)
    ├── hopeInfo.cs              # 호프 상세정보
    ├── naInfo.cs                # 모아나 상세정보
    ├── spyticket.cs             # 스파이더맨 상영 일정 선택
    ├── hotic.cs                 # 호프 상영 일정 선택
    ├── natic.cs                 # 모아나 상영 일정 선택
    ├── spysit.cs                # 스파이더맨 좌석 선택
    ├── hosit.cs                 # 호프 좌석 선택
    ├── nasit.cs                 # 모아나 좌석 선택
    ├── mocal.cs                 # 관람 요금 계산 및 결제 확인
    ├── Resources/              # 포스터 등 이미지 리소스
    └── Properties/             # 리소스 정의
```

각 화면의 UI 배치와 리소스는 해당 `*.Designer.cs`, `*.resx` 파일에서 관리합니다.

## 🔧 환경 설정 및 실행

1. Windows 환경에서 .NET 6 프로젝트를 빌드할 수 있는 Visual Studio와 **.NET 데스크톱 개발** 구성 요소를 준비합니다.
2. `project.sln` 파일을 엽니다.
3. `project`를 시작 프로젝트로 지정한 뒤 빌드하고 실행합니다.
4. 메인 화면에서 영화 선택 → 날짜·시간 선택 → 좌석 선택 → 요금 계산 및 결제 확인 순서로 이용합니다.

예고편 기능은 코드에 지정된 다음 Microsoft Edge 실행 경로를 사용합니다. 설치 경로가 다르면 각 상세정보 화면의 `ProcessStartInfo` 경로를 수정해야 합니다.

```text
C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

## 🚀 향후 개선 사항

- 영화별로 중복된 상영 일정·좌석 화면을 공통 Form과 영화 데이터 모델로 통합
- 상영 시간 버튼의 표시값과 다음 화면에 전달하는 시간값 일치 여부 정리
- 선택 좌석 수와 관람 인원 수의 일치 여부 검증
- 결제 전 총액 계산, 세부 결제 옵션 선택, 환불 동의 여부 검증 강화
- 데이터베이스를 연동하여 예매 내역 저장 및 예약된 좌석의 중복 선택 방지
- 결제 확인 화면에 영화명·날짜·시간을 함께 표시하도록 전달 정보 확장
- 예고편을 기본 브라우저로 실행하여 특정 설치 경로에 대한 의존성 제거
